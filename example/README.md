# Example month

`MZS_MRR_2020-11_5min.nc` is November 2020 of the MRR-2 record at Mario
Zucchelli Station, taken unchanged from the published archive:

> Roversi, G., Bracci, A., and Baldini, L.: MRR-2 vertical profiles at Mario
> Zucchelli Station, Zenodo, https://doi.org/10.5281/zenodo.7907540

It is here so that both scripts run as soon as the package is unpacked. The
month carries 4561 five-minute steps at 53 % coverage, of which 310 contain
hydrometeors. It is one month of a four-year record and its shares are not the
published statistics: virga is 41 % of the bearing profiles here against 38 %
over the four years, and the accumulation excess at the emulated heights is
much larger than the published one, because a single intense event weighs
heavily on one month.

Point the scripts at the full archive to reproduce the numbers of the paper.
The README at the top level says how.
